Class Diagram
Struktur model Eloquent dan relasi antar entitas database
User
Atribut
+ id: bigint (PK)
+ name: string
+ email: string (unique)
+ password: hashed
+ role: enum
kepala_cabang | admin_acc | admin_eksp
+ email_verified_at: datetime
+ timestamps
Method
+ resis(): HasMany
+ expenses(): HasMany
+ incomes(): HasMany
Resi
Atribut
+ id: bigint (PK)
+ nomor_resi: string (unique)
+ nama_pengirim: string
+ nama_penerima: string
+ alamat_tujuan: string
+ berat_barang: decimal(8,2)
+ tarif: decimal(15,2)
+ status: enum
tiba | diproses | kurir | selesai
+ catatan: text? (nullable)
+ user_id: FK(users.id)
+ timestamps
Method
+ user(): BelongsTo
+ incomes(): HasMany
+ generateNomorResi(): string
Expense
Atribut
+ id: bigint (PK)
+ tanggal: date
+ kategori: string
+ nominal: decimal(15,2)
+ keterangan: text? (nullable)
+ user_id: FK(users.id)
+ timestamps
Method
+ user(): BelongsTo
Income
Atribut
+ id: bigint (PK)
+ tanggal: date
+ sumber: enum
resi | lainnya
+ nominal: decimal(15,2)
+ keterangan: text? (nullable)
+ resi_id: FK? (nullable)
+ user_id: FK(users.id)
+ timestamps
Method
+ user(): BelongsTo
+ resi(): BelongsTo
Relasi Antar Entitas — ERD Style
hasMany/belongsTo (Resi)
hasMany/belongsTo (Expense)
hasMany/belongsTo (Income)
